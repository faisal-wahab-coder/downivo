# 10.7 Universal Viewer

**Package:** `universal_viewer`  
**UI:** `UniversalViewerScreen` pushed from Files/Downloads open when mime is video/audio. Images use `ImageGalleryScreen` from Files (tap) and file details Open.

Uses `video_player`. Other types use `open_filex` (system handler).

Do not build a full office/PDF suite. Images use in-app `Image.file` + `PageView` (swipe siblings, pinch-zoom).
