# 10.4 Download Wizard

**Not a route.** `DownloadWizardDialog` (`AlertDialog`).

## Fields

- URL (required)
- Optional file name
- Priority: Low / Normal / High / Urgent

## Entry

Downloads FAB, empty CTA, intake “Download” confirm.

## Exit

Cancel, or Download → `enqueueUrlFlow`. If `discoverAllResources` returns >1 item, open `MediaSelectionSheet` instead of silent single enqueue.

## Validation

Invalid URL snackbar after submit.

## Media selection sheet

`MediaSelectionSheet` + `_MediaThumbnailCard`. None / All / toggle. Shows thumbnailUrl, mimeType. Title/platform on model; UI is thumbnail-led.

## Format picker

`FormatPickerSheet` when `formats.length > 1` and the user has not already picked a format. Settings `preferredQuality` / `preferredFormat` skip the picker when they match a format label (not for TikTok watermark). TikTok with/without watermark is always offered.
