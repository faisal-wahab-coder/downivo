# 10.2 Home Dashboard

**Route:** `/home`  
**Widget:** `packages/app_core/lib/src/features/home/home_screen.dart`

## Purpose

Primary paste surface + snapshot of storage, intake, and queue.

## Layout (top → bottom)

1. `UdmScaffold` title Home
2. Hero `UrlInputField` (paste, validate, resolve)
3. `MediaPreviewCard` when resolved (thumbnail, title, platform badge, Download, more/quality)
4. Unsupported/invalid helpers when needed
5. `StorageDashboard` — tap → Files
6. Shortcuts: Files, QR, clipboard history, Browser, Search
7. Active downloads (max 3 cards)
8. Recent completed (max 5) + View all → history

## URL field states

empty / focused / typing / invalid / resolving / resolved / unsupported / error

## Actions

Paste, Download, format/quality more, navigate to other features.

## Empty

Welcome empty if no tasks. Storage may show “Scanning storage…” or “Storage unavailable”.
