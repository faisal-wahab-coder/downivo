# 10.1 Onboarding

**Route:** `/onboarding`  
**Widget:** `OnboardingFlow` + `design_system` `onboarding_widgets.dart`

## Purpose

First-run setup. Five steps.

## Entry / exit

Cold start when `SharedPreferences.onboarding_complete != true`. Finish → set flag → `/home`.

## Steps (rebuild this sequence)

1. Welcome — title **Welcome to Downivo**, body **Download. Manage. Enjoy.**, primary **Get started**
2. Storage initialization (create category folders)
3. Notifications permission
4. Camera permission (QR)
5. Clipboard / complete

## States

Step index 0–4, loading during init, permission granted/denied/permanently denied, snackbar on setup error, button to open OS settings.

## Do not

Add account login, cloud, or extra permission types.
