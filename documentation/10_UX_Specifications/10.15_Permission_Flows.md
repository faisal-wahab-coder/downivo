# 10.15 Permission Flows

Permissions via `packages/permissions` + `permission_handler`.

`AppPermission`: notifications, camera, clipboard.

## Onboarding

Request each relevant permission. If permanently denied, offer **open OS settings**.

## Runtime

QR screen needs camera. Clipboard monitor needs clipboard permission where the OS requires it. Notifications for download progress (Android 13+ `POST_NOTIFICATIONS`).

Foreground service types declared in the manifest (`dataSync`).

No standalone `/permissions` GoRoute.
