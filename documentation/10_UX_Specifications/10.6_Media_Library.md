# 10.6 Media Library

**There is no Media Library tab.** Recreate this UX as **Files** (`/files`).

Backend: `packages/media_library`. UI: `files_screen.dart`, `image_gallery_screen.dart`, `file_detail_screen.dart`.

## Root

Category folders (`StorageCategory.folderName`) with counts.

## Folder

File rows: thumbnail, name, type, size, date, Delete, more → `FileActionsSheet`. Long-press selects the file. While files are selected, the app bar offers Move to folder and Clear selection. **New folder** (inside a category, not at the root) creates a subfolder. **Move to folder** lists that category’s folders, New folder, and the other categories. List default; grid toggle fills the tile with the image. Tap an image opens `ImageGalleryScreen` (not details).

`FileActionsSheet` also has **Open with** (Android chooser) and **Show in Files** (jumps to the file’s folder). Completed downloads expose the same three actions.

## Search / sort / filter

In-list search. `LibrarySort`: newest, oldest, nameAsc, nameDesc, largest, smallest. `FileFilterSheet`: size + modified.

## Image gallery (push)

Full-screen image with pinch-zoom. Swipe left/right through other images in the current folder or Files search results. App-bar 3-dot (`File details`) → file detail. Bottom **More actions** (icon + label) → `FileActionsSheet` for the current photo. Tile **More actions** stays on the list/grid row.

## File detail (push)

Entry: gallery 3-dot or tap of a non-image file. Metadata only (Name, Source, Category, Size, Modified, Type, Location). App-bar 3-dot → `FileActionsSheet`. No stacked Open / Save to Gallery / More actions / Delete buttons.

## Import

Banner for unsorted files → move into a category.

## States

Loading spinner, error EmptyState, empty root/folder, search empty/error/results, pending imports.
