# 10.5 Smart Browser

**Route:** `/browser`  
**Widgets:** `browser_screen.dart`, `browser_home.dart`, `browser_sheets.dart`  
**State:** `browser_providers.dart`  
**Engine package:** `packages/browser`

## Chrome

`_BrowserToolbar`: back, forward, close, refresh, home, address field, tabs, bookmarks, history, page-downloads, bookmark toggle. Loading spinner on toolbar.

## Start page (`BrowserHome`)

Shortcuts: Google, GitHub, Archive.org + search field. Not a generic “empty webview”.

## Behavior

- Address submit loads WebView (`webview_flutter`, web: `webview_flutter_web`)
- Invalid URL snackbar
- Multi-tab session persisted via browser package (uuid + shared_preferences)
- History and bookmarks sheets
- Download detector → sheet → download wizard / enqueue

## Do not

Invent a second tab engine. Use existing session model.
