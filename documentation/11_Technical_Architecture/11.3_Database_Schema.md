# 11.3 Database Schema

Implementation: `packages/database/lib/src/app_database.dart`  
**Engine: sqflite, schemaVersion = 4** (not Drift).

See also [22_Database.md](../22_Database.md) and [13.6](../13_Data_Architecture/13.6_Download_Database_Schema.md).

## downloads

| Column | Type | Notes |
|--------|------|-------|
| id | TEXT PK | uuid |
| url | TEXT NOT NULL | |
| domain | TEXT | |
| file_name | TEXT NOT NULL DEFAULT '' | |
| file_path | TEXT | |
| file_size | INTEGER | |
| mime_type | TEXT | |
| status | TEXT NOT NULL | enum storageValue |
| priority | TEXT NOT NULL DEFAULT 'NORMAL' | |
| progress | REAL NOT NULL DEFAULT 0 | 0–1 |
| created_at | TEXT NOT NULL | ISO-8601 |
| started_at | TEXT | |
| completed_at | TEXT | |
| updated_at | TEXT NOT NULL | |
| thumbnail_url | TEXT | added v4 |
| platform | TEXT | added v4 |
| title | TEXT | added v4 |

Indexes: `idx_downloads_status`, `idx_downloads_created_at DESC`, `idx_downloads_updated_at DESC`, `idx_downloads_file_path`.

## app_metadata

key TEXT PK, value TEXT NOT NULL, updated_at TEXT NOT NULL.

Used for `db_initialized` and other KV.

## API (`AppDatabase`)

insertDownload, getAllDownloads, getDownloadById, updateDownload, updateDownloadFilePath, deleteDownload, deleteDownloadsWithStatuses, getMetadata, setMetadata, markInitialized, isInitialized, close.

`DownloadRecord.toMap` / `fromMap` column names **must** match.
