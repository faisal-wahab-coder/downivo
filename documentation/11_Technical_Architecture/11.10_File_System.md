# 11.10 File System

Package `storage`.

## StoragePaths

Resolve app download root (`path_provider` on IO). Create category directories via `StorageInitializer`.

`StorageCategory` folder names: Videos, Images, Audio, Documents, Archives, APK, QR Downloads, Favorites, Vault, Temp, Logs.

## FileStore

Interface + `IoFileStore` / `WebFileStore` / `MemoryFileStore` (tests). Factories via conditional imports.

## Volume

`StorageInfo` + StatFs on Android. Web stub without volume stats.

## Library

`media_library` scans these folders, not MediaStore as the source of truth (managed library is the app tree). Open/share uses `open_filex` / `share_plus`. **Save to Gallery** copies photos and videos into MediaStore (album `Downivo`) via `gal`; originals stay in the app tree.
