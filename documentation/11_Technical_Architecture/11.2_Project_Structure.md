## Package ownership

| Package | Owns |
|---------|------|
| app_core | bootstrap, providers, router wiring, screens |
| navigation | MainShell, OnboardingFlow, shell chrome |
| design_system | theme, tokens, generic widgets |
| download_engine | queue, Dio, resolvers, DownloadTask |
| database | AppDatabase, DownloadRecord |
| storage | paths, categories, FileStore, volume stats |
| media_library | scan, LibraryFile, favorites, actions |
| browser | tabs/history/bookmarks/url utils/detector |
| content_intake | analyzer, clipboard store, share models |
| job_manager | FG service coordinator, connectivity |
| notifications | local notifications |
| permissions | AppPermission requests |
| performance | TTL/LRU/throttle/metrics |
| search | AppSearchService |
| universal_viewer | AV player screen |
| shared_types | enums, AppRoutes |
| shared_utils | transfer format helpers |

## melos.yaml members

Exactly the packages listed above plus `apps/mobile` and `apps/web`. Scripts: analyze, test, qa, format.
