# 11.1 System Architecture

```
User
  │
  ▼
Flutter UI (app_core features)
  │  Riverpod
  ▼
DownloadManager  MediaLibrary  BrowserSession  Intake
  │                 │                │            │
  ├─ Dio            ├─ FileStore     WebView      Clipboard/Share/QR
  ├─ ContentProviderRegistry
  ├─ DownloadRepository → AppDatabase (sqflite)
  └─ StoragePaths / FileStore
         │
         ▼
   Android FS  ·  notifications  ·  ForegroundService (dataSync)
```

**Process model:** one Flutter isolate UI + foreground service isolate for `flutter_foreground_task`. Communication port initialized in `main()`.

**Web:** same `app_core`, sqflite ffi web, memory/web file store, no camera/share/FG service.

There is no backend server. No sync. No accounts.
