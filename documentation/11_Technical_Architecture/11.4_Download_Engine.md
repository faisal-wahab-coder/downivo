# 11.4 Download Engine

Package: `download_engine`. Public barrel: `lib/download_engine.dart`.

## DownloadManager

Constructor:

- required `DownloadRepository`, `StoragePaths`
- optional `FileStore`, `Dio`, `ContentProviderRegistry`
- `maxConcurrent = 3`, `maxRetries = 3`
- Dio connectTimeout 30s, receiveTimeout 30m

In-memory: `_tasks`, `_cancelTokens`, `_retryCounts`, `_queueOrder`.  
Broadcast `tasksStream`. Progress emits gated at 250ms.

## Responsibilities

1. Validate URL (`url_validator.dart`)
2. Resolve social or direct (`ContentProviderRegistry`)
3. Filename (`filename_resolver.dart`)
4. Persist via repository → sqflite
5. Execute with Dio; Range via `range_response_parser.dart`
6. Write through `FileStore` into category folder
7. Pause/resume/cancel/retry/reorder/pauseAll/resumeAll
8. Restore on create
9. `clearHistory` → delete terminal statuses in DB, keep files

## DownloadTask fields

id, url, fileName, filePath, fileSize, mimeType, status, progress, bytesReceived, speedBytesPerSec, createdAt, updatedAt, errorMessage, priority, thumbnailUrl, platform, title.

`isActive`: downloading | preparing | queued | verifying.

## DownloadRepository

Maps `DownloadTask` ↔ `DownloadRecord`.
