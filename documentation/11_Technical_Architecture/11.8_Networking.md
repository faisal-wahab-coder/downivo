# 11.8 Networking

There is **no** standalone `networking` package in the Melos workspace.

All HTTP is **Dio** inside `download_engine`:

- Shared `Dio` on `DownloadManager`
- Timeouts: connect 30s, receive 30m
- Range requests for resume
- Per-task `CancelToken`
- Optional `requestHeaders` from `DiscoveredResource` (social CDNs)
- `UrlValidator` for user input

Connectivity monitoring is `connectivity_plus` in `job_manager`, not Dio interceptors.

WebView networking is the system WebView, separate from Dio.
