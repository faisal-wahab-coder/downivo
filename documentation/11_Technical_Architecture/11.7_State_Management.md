# 11.7 State Management

**flutter_riverpod ^2.6.1** only.

## Graph roots (bootstrap overrides)

- `sharedPreferencesProvider`
- `appInitializerProvider`
- `defaultStoragePathProvider`
- `downloadManagerProvider`
- `goRouterProvider`

## Feature providers (app_core)

| File | Role |
|------|------|
| `download_providers.dart` | task list, history, enqueue |
| `library_providers.dart` | browse, query, location, imports |
| `settings_provider.dart` | theme, clipboard, path, quality/format |
| `browser_providers.dart` | session |
| `intake_providers.dart` | clipboard/share |
| `performance_providers.dart` | metrics |

UI listens to `DownloadManager.tasksStream` through a provider — that stream **is** the event bus.

Settings persisted with `shared_preferences`, not Hive.
