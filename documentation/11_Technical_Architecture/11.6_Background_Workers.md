# 11.6 Background Workers

There is **no WorkManager job graph** in V1.

## As-built

- `packages/job_manager` + `app_core` `download_background_scope.dart`
- `flutter_foreground_task` ^11.0.1
- Manifest service: `com.pravera.flutter_foreground_task.service.ForegroundService` type `dataSync`
- `FlutterForegroundTask.initCommunicationPort()` in `main()`
- `WithForegroundTask` wraps the app
- `connectivity_plus` — pause on disconnect, resume on reconnect
- `packages/notifications` — progress; actions pause/cancel

Do not add a second background scheduler package.
