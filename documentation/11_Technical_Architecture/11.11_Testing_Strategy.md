# 11.11 Testing Strategy

| Layer | Where |
|-------|--------|
| Unit | `download_engine/test` (resolvers, manager, validator, range parser) |
| Unit | `database/test/database_test.dart` (schema, migrations) |
| Unit | `storage/test`, `content_intake/test`, `browser/test`, `media_library/test` |
| Widget | `app_core/test` history + onboarding; `apps/mobile/test` |
| Integration | enqueue persistence; history clear keeps files (`bootstrap_test` / app_core) |
| QA docs | `downivo/qa/test-cases/**` (platform suites) |

`scripts/ci.sh` runs pub get, `flutter analyze --no-fatal-infos`, and `flutter test` for the package list (shared_types → app_core → mobile).

Use `sqflite_common_ffi` in tests. Fake `PathProvider` where needed.

Copy assertions: “Welcome to Downivo”, “Get started”, “Download detected”, history semantics `{fileName}, {status}`.
