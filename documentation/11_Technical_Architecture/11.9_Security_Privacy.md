# 11.9 Security and Privacy

- On-device metadata only
- No analytics package wired in V1 (folder may exist empty). Planned telemetry: [31_Observability_Analytics.md](../31_Observability_Analytics.md) — never send full URLs, tokens, cookies, or file contents
- HTTPS URLs; user can still enter http (validator allows http/https)
- Android 13+ notification permission
- Camera only for QR
- Clipboard opt-in
- Share target only when user shares into the app
- Release: R8 + ProGuard (`RELEASE.md`)
- Do not log full URLs with tokens in production prints
- WhatsApp private media hosts classified, not downloaded
- No DRM circumvention

See [23_Security.md](../23_Security.md).
