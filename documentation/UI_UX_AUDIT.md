# UI/UX Audit (as-built snapshot)

Captured for rebuild so visual polish matches V1, not a redesign.

## Keep

- Light-first MD3, electric blue light / cyan dark
- Home paste hero as the primary download path
- Platform as badge, not full-card brand colors
- Downloads as operational queue (groups + reorder)
- Files as folder browser, not a gallery-first Instagram clone
- Browser start page shortcuts (Google, GitHub, Archive.org)
- Intake copy **Download detected**

## Known V1 limitations (do not “fix” in a replica unless asked)

- Wizard dialog is generic
- Media selection sheet is dense
- Settings duplicates theme chrome / exposes performance internals
- Download folder path is display-only
- No notification center
- Nested ListView in Files (known)
- QR UI is basic camera + copy
- Share sheet may lack thumbnail at intake time

A replica should match these behaviors, not silently redesign IA.
