# 18. Browser

**Package `browser`:** tabs, history, bookmarks, URL utils, download detector, uuid + shared_preferences.

**UI `app_core`:** `BrowserScreen`, `_BrowserToolbar`, `_BrowserWebView`, `BrowserHome`, `browser_sheets.dart`.

Start page shortcuts: Google, GitHub, Archive.org. Detected downloads enqueue through the same wizard/engine path as Home.
