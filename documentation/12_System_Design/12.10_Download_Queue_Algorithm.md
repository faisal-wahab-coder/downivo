# 12.10 Download Queue Algorithm

- At most **3** tasks in downloading/preparing/verifying concurrently
- Queued order = `_queueOrder` (user-reorderable)
- Priority stored on the task; use it when selecting the next queued item (higher urgency first; stable with queue order)
- Pause removes from active slots and keeps partial file for Range resume
- Cancel deletes in-flight request (`CancelToken`) and should not leave a completed record
- Retry increments `_retryCounts` up to `maxRetries = 3`
