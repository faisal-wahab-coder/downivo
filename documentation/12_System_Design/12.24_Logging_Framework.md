# 12.24 Logging Framework

**V1 replica:** centralized `AppLogger` in `packages/analytics`. URLs and tokens are stripped.

## Levels

`DEBUG` · `INFO` · `WARNING` · `ERROR` · `FATAL`

## Rules

- Structured fields: `downloadId`, `platform`, `mediaType`, operation name.
- **Never** log full URLs, query parameters, cookies, or auth tokens.
- Resolver, downloader, storage, permission, and network logs go through `AppLogger`.
- Release: sanitized breadcrumbs / Crashlytics non-fatals for errors; do not dump verbose URL traces on device.

## Example

```
INFO  Download started  downloadId=83921  platform=youtube  mediaType=video
```

Crash reporting (Firebase Crashlytics) is specified in [12.23](12.23_Analytics_Architecture.md), not as a second ad hoc `debugPrint` path.
