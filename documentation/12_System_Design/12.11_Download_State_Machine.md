# 12.11 Download State Machine

```
queued → preparing → downloading → verifying → completed
                 ↘ paused ⇄ downloading
                 ↘ failed → (retry) → queued/preparing
any active → cancelled
```

Storage values: QUEUED, PREPARING, DOWNLOADING, PAUSED, COMPLETED, FAILED, CANCELLED, VERIFYING.

History lists completed, failed, cancelled. Clear history deletes those rows only.
