# 12.8 Feature Module Architecture

Live features under `app_core/lib/src/features/`:

- `home/`
- `downloads/`
- `files/`
- `browser/`
- `settings/`
- `intake/`
- `search/`

Each folder: screens + feature-only widgets. Cross-feature navigation uses `context.go` / `Navigator.push`. Shared providers in `app_core/lib/src/providers/`.
