# 12.31 Performance Optimization

`packages/performance`: TTL cache (library scan 30s), LRU cache, `ThrottleGate` 250ms, metrics (`recordStartup`). SQLite indexes on created_at/updated_at/file_path. Virtualized lists. Parallel bootstrap futures. Downsized thumbs. Lifecycle-aware clipboard polling.

Remote traces (Firebase Performance / Sentry) are a later Observability phase ([31](../31_Observability_Analytics.md) Phase 10). They do not replace this package.
