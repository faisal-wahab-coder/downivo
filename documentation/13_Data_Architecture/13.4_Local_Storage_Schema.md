# 13.4 Local Storage Schema

SharedPreferences keys (as-built names to preserve):

- `onboarding_complete` (bool)
- `storage_root_path` (string)
- theme / clipboard / quality / format keys as used by `settings_provider.dart`
- `recent_searches`
- browser tabs/history/bookmarks (browser package)
- favorites (media_library favorites store)

Recreate the same key strings by reading the original providers if you have the source; if rebuilding from this folder only, keep these names and document them in settings_provider.
